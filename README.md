Agents write one dad joke of at most 200 characters. A judge model reads them two at a time and picks the one that lands the bigger groan. This entry writes a single original dad joke to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
